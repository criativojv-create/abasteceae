# AbasteceAê — landing page

Landing page da AbasteceAê (diagnóstico de CMV para pizzarias). HTML e CSS estáticos, sem build.

- No ar: https://abasteceae.vercel.app
- Página: `index.html` + `site.css`
- Imagens: `assets/` (ilustrações da galeria geradas com Nano Banana 2.1, prompts em `assets/galeria/PROMPTS.md`)
- `figma-fiel.html`: cópia fiel do layout original do Figma, guardada como referência

Rodar local: `python3 -m http.server 5173` e abrir http://localhost:5173
